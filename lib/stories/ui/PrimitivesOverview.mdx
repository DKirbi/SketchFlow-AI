# Primitives

**Primitives** are the atomic LOFI Kit controls — one BEM block each, grayscale, monospace, no colour. Demos and **component sets** compose these; they do not replace them.

Each primitive has its own Docs page with interactive controls. Prefer the set when the same cluster repeats (footer, filter row, P7). Use the primitive when you need a single control.

## How this folder relates to sets

| Need | Use |
|---|---|
| One button, field, table, or modal | Primitive in this folder |
| Recurring cluster with action roles | Component set (`kind` + JSON config) |
| Full P1 workspace or tool frame | `upl-shell` / `tool-shell` |

See **LOW FI Design system / LOFI Kit** for the catalog, tokens, and visual rules, and **Component sets / Overview** for config-driven compositions.
