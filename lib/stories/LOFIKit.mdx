**LOFI Kit** is a low-fidelity design tool — a grayscale, monospace component library for fast prototyping. It is used here to render live pattern examples. It is **not** the production design system; production UIs use **Podium**.

Component stories with interactive prop controls live under **LOW FI Design system → Primitives**. Config-driven compositions with usage snippets live under **LOW FI Design system → Component sets**.
